# StreamSphere

StreamSphere is a full-stack video streaming platform inspired by YouTube. It allows users to sign up, log in, watch videos, create channels, and upload content. The platform is designed to provide a seamless video streaming and content management experience.

---

## Features

- User Authentication (Sign Up / Login)
- Watch Videos
- Upload Videos
- Create and Manage Channels
- Store and Manage Video Data
- Browse and Explore Content
- Structured Database Management
